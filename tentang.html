Tentang Program

Digitalisasi UMKM Desa Jagapura Lor

🎯 Latar Belakang

Desa Jagapura Lor memiliki banyak pelaku UMKM yang bergerak di berbagai sektor seperti makanan, minuman, jasa, dan pertanian. Namun, sebagian besar dari mereka masih belum memanfaatkan teknologi digital untuk memasarkan produknya.

Program Digitalisasi UMKM ini hadir sebagai solusi untuk membantu para pelaku UMKM desa agar lebih dikenal luas melalui katalog digital yang dapat diakses oleh masyarakat kapan saja dan di mana saja.

💡 Tujuan Program

  • Mendigitalisasi data UMKM di Desa Jagapura Lor
  • Meningkatkan promosi dan pemasaran produk UMKM
  • Mempermudah masyarakat menemukan produk/jasa UMKM desa
  • Mendukung pertumbuhan ekonomi desa berbasis teknologi

🛠️ Teknologi yang Digunakan

Aplikasi katalog ini dibangun menggunakan teknologi web modern yang ringan dan mudah diakses:

  • HTML, CSS, JavaScript — untuk antarmuka website
  • JSON — sebagai database data UMKM
  • GitHub Pages — untuk hosting gratis
  • Google Forms & Sheets — untuk pendataan UMKM

🔄 Alur Sistem

PENDATAAN (Google Forms) ↓ DATA MASUK (Google Sheets) ↓ VALIDASI (Admin Desa / KKM) ↓ UPDATE DATA (umkm.json) ↓ UPLOAD (GitHub Repository) ↓ PUBLISH (GitHub Pages) ↓ 🌐 KATALOG ONLINE ↓ ├─ Masyarakat: lihat & hubungi UMKM └─ UMKM: promosi & penjualan

👥 Tim Pengembang

Program ini dilaksanakan oleh mahasiswa KKM (Kuliah Kerja Mahasiswa) sebagai bentuk pengabdian kepada masyarakat, bekerja sama dengan Pemerintah Desa Jagapura Lor.
